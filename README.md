# 溯源科普

以配音史及相关媒介史、文化史和技术史为起点，通过双线独立研究、交叉质询和证据核验，形成可追溯的研究成果，并转化为视频内容。

## 项目目录

- `01-研究方法/`：协作规约和各研究线的方法。
- `02-选题/`：选题构想、研究问题和立项记录。
- `03-资料库/`：来源索引、资料摘录和核验记录。
- `04-专题研究/`：按专题保存双线研究、交叉质询和综合结论。
- `05-视频制作/`：脚本、素材清单、配音与剪辑记录。
- `06-发布与反馈/`：发布信息、勘误和观众反馈。
- `模板/`：可复制的研究记录模板。

## 建议工作流程

1. 在选题目录记录问题、范围和立项原因。
2. 在资料库记录来源，并保留可定位的出处。
3. 为专题建立独立文件夹，分别开展 A、B 线研究，再记录质询和综合结论。
4. 将经过核验的结论转化为脚本，并保留与来源的对应关系。
5. 发布后记录反馈与勘误，必要时回到研究环节修订。

具体研究原则以 [双线研究方法论与协作规约](01-研究方法/双线研究方法论与协作规约.md) 为准；A 线方法见 [A线研究方法](01-研究方法/A线：证据约束型辩证研究方法.MD)。B 线方法待建立。

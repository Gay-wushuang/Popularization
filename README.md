# 溯源科普 · Popularization

“溯源科普”是开展多个科普项目的总工作空间，用于组织选题、资料、研究、内容制作与发布反馈。各子项目独立定义研究范围、协作方式和成果形式，并积累可追溯、可修订的知识成果。

项目负责人统一负责路线、选题、调查、分析、论证和最终结论；助理提供可核查的材料与分析。不设固定双研究者结构。

当前升级：通用研究框架 V1，2026-11-10，工作分支审阅稿，未提交或推送。旧双线制度已停用，V1 经负责人审阅后用于新研究；本次不开展实际专题研究。

## 目录结构

- `项目/`：各子项目的独立工作目录。
- [研究方法](研究方法/README.md)：所有项目共同的研究路线、信源、方法库、证据链与资料治理规范。
- `项目/配音史/`：现有配音史项目，包含研究方法、选题、资料库、专题研究、视频制作和发布反馈。
- [模板](模板/README.md)：按问题选用的通用记录工具，不要求全部填写。
- [AGENTS.md](AGENTS.md)：研究代理的执行规则与关键入口。

## 新建子项目

1. 阅读全局方法入口，明确具体问题，在下表查重并登记永久项目代码。
2. 在 `项目/项目名称/` 建立 README，从[研究立项与项目配置](模板/01-研究立项与项目配置.md)填写领域配置，引用全局版本并记录领域差异、负责人、方法与验收条件。
3. 按该模板的专题部分明确范围、可行性、获取权限与停止条件，由负责人确认后开研。
4. 首条实际记录出现时建立登记簿，按[编号规范](研究方法/04-证据链与辩证论证规范.md)分配 ID、记录路径与版本。按需增加线索、来源、分析与发布记录。

不要求新项目复制配音史目录或制作视频，不为展示架构预建空文件。

全局规范是共同底线，领域配置可以加严，不能降低证据标准。规范正文集中维护，项目不复制整套方法论；冲突记录后交负责人处理，不擅自修改制度。

## 模板管理

通用模板放在根目录 `模板/`；只适用于某个子项目的模板放在该子项目的 `模板/`。使用通用模板时，先复制到子项目或具体专题中再修改，避免项目之间相互影响。需要修改共享模板时，应明确其对所有使用项目的适用性。

记录所据模板和规范版本，不自动覆盖既有副本。旧制度仅供[历史查阅](项目/配音史/历史归档/双线研究V1/README.md)。本次基线、迁移映射、变更清单与验收见[迁移与验收报告](研究方法/迁移与验收报告.md)。

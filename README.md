# 溯源科普

“溯源科普”是开展多个科普项目的总工作空间，用于组织选题、资料、研究、内容制作与发布反馈。各子项目独立定义研究范围、协作方式和成果形式，并积累可追溯、可修订的知识成果。

配音史是其中一个子项目。其相关媒介史、文化史和技术史研究，以及现有双线研究方法文档，归属于该子项目。

## 目录结构

- `项目/`：各子项目的独立工作目录。
- `项目/配音史/`：现有配音史项目，包含研究方法、选题、资料库、专题研究、视频制作和发布反馈。
- `模板/`：可供各子项目按需调整的记录模板。

## 新建子项目

在 `项目/` 下以项目名称建立文件夹，并添加项目说明，明确目标、范围、成果形式和当前进度。可根据实际需要建立选题、资料、研究、制作、发布等目录。

项目专属资料放在对应子项目内；确实适用于多个项目的方法或资源，经过整理后再作为共享内容保存。双线研究和视频制作是现有配音史项目采用的工作方式，其他子项目可根据需要选择。

## 模板管理

通用模板放在根目录 `模板/`；只适用于某个子项目的模板放在该子项目的 `模板/`。使用通用模板时，先复制到子项目或具体专题中再修改，避免项目之间相互影响。需要修改共享模板时，应明确其对所有使用项目的适用性。

# 配音史模板使用入口

当前使用[根目录通用模板 V1](../../../模板/README.md)，本目录不复制维护同一套表。领域差异见[领域研究配置](../01-研究方法/领域研究配置.md)。

| 工作 | 使用根模板 | 项目内保存建议 |
| --- | --- | --- |
| 问题与范围 | 01 的专题部分 | `02-选题/` |
| 传闻、来源与核验 | 02、03 | `03-资料库/` |
| 口述、评论与问卷 | 04、05、06，按需 | 资料区或专题，受限原件仓库外 |
| 技术和设备验证 | 07，按需 | 专题及日志索引 |
| 命题、分析、反证、结论 | 08、09、10 | `04-专题研究/` |
| 导航、时间线、实体和版本 | 11，按需 | 专题总览，链接项目登记簿 |

作品版本、档号、原始音轨、时间码、转录校对和素材使用权限按配置补充到实际记录，不改根模板的证据底线。复制后检查路径；不要创建没有真实内容的表。

原七份模板和旧使用说明完整保存在[历史归档](../历史归档/双线研究V1/README.md)，均已停用，不继续填写或作为启动条件。

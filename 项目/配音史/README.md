# 配音史

本项目是 Popularization 通用研究框架 V1 的第一个领域适配项目，代码 `DUB`。研究配音史及相关媒介、文化、技术、产业与职业实践，成果可为研究文档、资料札记、时间线或视频，由具体立项决定。

项目负责人统一负责研究路线与最终判断；助理协助检索、调查、核验与分析，不设固定双研究者。V1 配置为 2026-11-10 迁移审阅稿，本次未确定第一期选题或开展实际研究。

## 工作目录

- [全局规范](../../研究方法/README.md)：共同研究标准，只在根目录维护。
- [01-研究方法](01-研究方法/README.md)：领域配置与专项要求入口。
- `02-选题/`：选题构想、研究问题和立项记录。
- `03-资料库/`：来源索引、资料摘录和核验记录。
- `04-专题研究/`：命题证据矩阵、分析反证、结论与版本索引。
- `05-视频制作/`：脚本、素材清单、配音与剪辑记录。
- `06-发布与反馈/`：发布信息、勘误和反馈。

通用记录工具只在[根模板目录](../../模板/README.md)维护；本地[模板说明](模板/README.md)只给适配提示。旧制度与旧模板在[历史归档](历史归档/双线研究V1/README.md)完整保留，已停用。


## 研究启动条件

先读全局规范与[领域研究配置](01-研究方法/领域研究配置.md)，由负责人提供并确认问题、范围、可行性与方法。不存在等待第二位研究者或交换独立稿的启动要求。正式记录按项目代码分配稳定 ID，首条实际资料出现时建立登记簿；不提前分配示例编号。

## 资料库组织

资料库先按实际资料积累，不预建大量空目录。第一批资料进入后，可按需要建立：来源索引、学术文献、机构与企业资料、原始档案、技术与开源资料、录音与影像、核验记录。分类可调整；同一资料尽量保留一份主记录，通过来源编号关联各专题和核验记录。

## 模板与实践

研究问题尚未确定。确认本次制度升级后，再选择边界清楚且资料可得的问题，使用全局模板创建实际记录，按案例复盘提出制度改进；不擅自更改规范。

# 配音史

本项目是“溯源科普”下的一个子项目，研究配音史及相关媒介史、文化史和技术史，并将研究成果转化为视频内容。

## 工作目录

- `01-研究方法/`：双线协作规约和 A 线方法；B 线方法待补充。
- `02-选题/`：选题构想、研究问题和立项记录。
- `03-资料库/`：来源索引、资料摘录和核验记录。
- `04-专题研究/`：双线研究、交叉质询和综合结论。
- `05-视频制作/`：脚本、素材清单、配音与剪辑记录。
- `06-发布与反馈/`：发布信息、勘误和反馈。

研究与协作要求见 [双线研究方法论与协作规约](01-研究方法/双线研究方法论与协作规约.md) 和 [A线研究方法](01-研究方法/A线：证据约束型辩证研究方法.md)。这两份文档中的“本项目”在当前目录下指配音史子项目；是否推广到其他子项目，应另行确定。


## 研究启动条件

A 线可以先独立开展研究。双线协作规约目前作为共同研究框架；B 线研究者自主确定研究方法，A 线方法不作为 B 线的默认标准。双方确认共同研究边界、资料共享安排与质询机制后，再正式启动双线研究。未完成的环节标记为待开展，不代填另一方观点。

## 资料库组织

资料库先按实际资料积累，不预建大量空目录。第一批资料进入后，可按需要建立：来源索引、学术文献、机构与企业资料、原始档案、技术与开源资料、录音与影像、核验记录。分类可调整；同一资料尽量保留一份主记录，通过来源编号关联各专题和核验记录。

## 模板与实践

研究记录见 [模板说明](模板/README.md)。复制模板到对应选题或专题后填写，保留模板本身供后续复用。下一步先确定一个范围有限、原始资料较易获取的真实问题；完成研究、内容转化及复盘后，再判断是否修订方法论。

# 配音史研究模板

这些模板服务于配音史子项目，不自动成为其他项目的要求。复制后填写，文件名建议包含专题编号与记录名称。记录版本、作者、日期，并用来源编号关联证据。

1. [选题立项表](01-选题立项表.md)：放入 `02-选题/`，先明确范围和可行性。
2. [资料来源核验表](02-资料来源核验表.md)：放入 `03-资料库/`，记录出处、定位和核验状态。
3. [A线独立论证表](03-A线独立论证表.md)：放入 `04-专题研究/专题名称/`。
4. [B线独立研究表](04-B线独立研究表.md)：由 B 线研究者自主调整，也可用自己的记录形式替代。
5. [双线交叉质询表](05-双线交叉质询表.md)：双方独立研究与共同机制确认后使用。
6. [综合结论表](06-综合结论表.md)：记录证据、分歧、传播表述和流程复盘。

[专题研究模板](专题研究模板.md)可作为专题总览，链接以上记录。独立研究阶段应如实注明状态，未开展的 B 线或交叉质询环节留待开展。模板不改变现有方法论正文。

第一期试验专题尚待确定。选题时优先考虑问题边界清楚、原始资料可获取、能在合理时间内完成核验的题目；实际完成一次研究与内容转化后，依据复盘决定是否调整流程。

## 独立稿封存与交换

Git Commit SHA 用于定位版本，不能证明研究者未提前接触另一方内容。正式双线研究按以下顺序执行：

1. 双方先确认研究边界、资料共享范围和开放安排。在互不可见的本地环境或独立私有仓库中完成独立稿；独立阶段不向公共仓库、共享分支或对方可见的私有空间推送独立稿及会暴露结论的记录。公开仓库的不同分支不能提供隔离。
2. 各自在独立环境提交完整独立稿及必要的依据记录，保存该提交与完整 SHA，并另行记录文件路径和完成时间。封存后保留原提交，不修改或替换封存版本；新增修订另作提交。
3. 双方均声明独立稿已完成后，交换完整 SHA 与路径，或由双方认可的协调者确认封存。此阶段先交换版本标识，不提前开放正文。
4. 双方确认均已封存后，按约定在同一轮交换中开放双方内容；双方材料均可访问后再进入交叉质询。记录完成声明、封存确认和实际开放时间。不得要求另一方在独立稿尚未完成时阅读已开放稿件。
5. 统一归档时保留原封存提交及可读取的文件，并核对交换记录中的 SHA。若公开仓库采用复制文件的方式归档，另记公开归档的 SHA、路径及与原稿内容一致的核对结果；原 SHA 不能被复制后的新提交 SHA 替代。归档前检查私有提交历史及附件是否含有不宜公开的材料，必要时只公开允许公开的副本，并保留原封存版本供双方核查。

若独立阶段已接触另一方内容，应如实记录接触时间、范围和可能影响，由双方决定继续、缩小独立性声明或重新研究；不能仅凭 SHA 宣称研究完全独立。上述安排仍须双方实际确认和执行，模板填写本身不构成独立性证明。

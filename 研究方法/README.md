## 最小记录与维护

小型研究可以在一份专题文档中分节记录立项、来源、证据矩阵、分析反证和结论复核；稳定 ID 仍登记，需要多人协作或资料增长时再拆文件。访谈、问卷、实验发生时才增加相应记录，不为每项资料重复生成多份表。

未知写“未知／待核验”，不适用写理由。主记录只维护一处，其他位置以编号、链接和精确位置引用。规范优先于模板，项目差异不得降低底线，冲突交负责人处理。

制度修订由负责人批准；模板副本注明所据版本，旧记录按原版本留存，迁移记映射。不将未实际实施的调查、复现或审核登记为完成。[迁移与验收报告](迁移与验收报告.md)仅记录本次升级，不要求每期重复填写。

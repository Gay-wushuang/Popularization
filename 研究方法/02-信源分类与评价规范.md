# 信源分类与评价规范

版本：V1.0；日期：2026-11-10；适用与状态见[全局入口](README.md)。记录工具见[来源模板](../模板/03-来源登记与核验.md)。

## 1. 分类与问题的关系

类型允许交叉，不是可信度排名。原始／二手属性相对于具体问题判断：旧论坛帖可直接记录当时话语，不能直接证明帖中事件。

| 类别 | 资料 | 特别核查 |
| --- | --- | --- |
| A 学术与正式出版 | 论文、专著、学位论文、会议、专业出版物 | 方法、原始依据、撤稿更正、同一研究的多个报告 |
| B 政府与公共机构 | 法规政策、统计、档案、公共机构报告 | 适用地区、生效版本、口径、职责与保存公开偏差 |
| C 企业与产业 | 公告、年报、产品文档、专利、合同、标准、产业记录 | 利益目的、宣称与实施差异、测试条件与版本 |
| D 新闻与媒体 | 新闻、调查报道、历史报刊、专业媒体 | 采访对象、转述链、编辑目的与时间差 |
| E 民间与舆论 | 论坛、贴吧、社交平台、博客、评论、影迷社群、传闻争议 | 删除编辑、匿名性、共同源头、平台与群体偏差 |
| F 口述与访谈 | 当事人、从业者、专家、见证者、参与者访谈回忆 | 同意范围、角色、记忆、诱导与转录准确性 |
| G 技术与数字 | 源码、Git 提交、软件版本、Issue、日志、元数据、数字档案、技术文档 | 完整 SHA、发布差异、时间戳、环境与生成过程 |
| H 数据与实验 | 统计、调查、测量、实验结果、原始数据集 | 定义、抽样、采集清洗、缺失、对照、误差和泄漏 |
| I 实物与现场 | 设备、出版物、录音、影像、实物档案、现场观察 | 保管链、版本、修复改装、观察与数字化条件 |
| J 聚合与辅助 | 搜索摘要、索引、AI 内容、资料导航 | 追溯实际主体与原件，入口不能替代被引用资料 |

## 2. 必须分开的评价维度

| 维度 | 问题 | 记录 |
| --- | --- | --- |
| 类型与原始性 | 什么材料，相对本命题是否原始？ | 类型及原始／二手／混合／未知，形成过程 |
| 真实性与出处 | 材料和身份是否可核验，是否冒名改编？ | 已核验／部分核验／待核验／存疑／已证实伪造及依据 |
| 可靠性 | 方法、接近事件程度、知识基础、利益和误差？ | 分项叙述，不以机构标签代替 |
| 独立性 | 是否转载、共同采访、同一数据或证人？ | 独立／依赖／部分依赖／未知，上游 SRC 和依赖组 |
| 命题证明能力 | 哪个位置如何作用于哪个 CLM？ | 矩阵中的支持关系、理由和局限 |
| 结论置信程度 | 综合论证可作多强判断？ | 结论记录维护，不贴到来源上 |

支持关系为直接支持／间接支持／仅提供背景／不支持／存在冲突。它是来源相对命题的关系，不能由真实性自动推出。同一来源可以真实记录错误说法，也可以反驳另一个命题。

不规定学术永远优于机构、一手永远优于二手。企业公告证明公开表述，不自动证明业绩；专利或代码不自动证明实际应用、法律有效性或普及。统计需核对定义及代表范围。

## 3. 获取与核验

实际使用的来源记录标题、作者主体、原始 URL／永久标识／馆藏号、版本、事件时间、形成时间、发布时间、访问时间、获取渠道与访问层级。未知保留未知；区间、时区与估计依据明确，不用文件修改时间代替事件时间。

关键摘录保留上下文，定位到页码、段落、表格、时间码、数据行／变量或代码文件位置。OCR、字幕、翻译和剪辑是派生资料，保留原件映射和校对状态。不能仅凭搜索摘要形成确定结论。

重要引用追溯原始出处，检查版本、更正、撤稿、编辑和删除。原件未取得时登记失败、已有层级和不能验证之处；按其对命题的重要性缩小判断或未决。保存按[资料治理](05-研究伦理版权与资料治理规范.md)。

交叉验证比较形成过程，不只比较文字。多篇转载、同一档案的研究或同一数据的图表须识别共同根源；独立性未知不得当作独立印证。

## 4. 传闻与低可信度线索

民间传闻、行业轶事、匿名爆料、论坛讨论、网络争议、回忆、观众评价、社群说法、未证事件和矛盾信息都可进入 LEAD；登记不代表真实或事件成立。

分别核查六个问题：说法是否存在；何时何地传播；原始或最早可追溯出处；转述路径；事件是否发生；是否影响社会认知。最早找到的记录只能叫“目前发现的最早记录”，不能未经论证叫传播起点。

帖子登记 SRC 可仅证明“该账号此时发布此说法”。所述事件另立 CLM，不能继承帖子的真实性状态。影响研究另需传播路径、受众等证据，阅读量与热度不能直接等同社会影响。

保留原话与研究者改写的区别、匿名限制、依赖和核查任务。线索状态为待查／调查中／已关联来源／暂缓／关闭，关闭写理由；不删除证伪线索。错误传闻仍可研究传播史与群体记忆，不能继续证明原事件。

## 填写约定

复制到实际项目，保留模板版本，调整所有复制后的相对链接。不适用写理由，未知写待核验；不把示例或空字段当研究结果。不自动更新已有副本。

所有实际记录保留项目／专题、负责人、创建与更新日期、记录版本、所据规范与模板版本、主路径。Git SHA 可由总览集中映射；未提交内容标“工作副本，未提交”，不得用当前 HEAD 冒充其版本。

一份主记录只维护一处：来源真实性在 03，命题支持关系在 08，推理与反证在 09，综合结论在 10，11 只作索引。小型研究可合并这些部分到一份文档，以稳定 ID 和锚点定位。按[编号规范](../研究方法/04-证据链与辩证论证规范.md)使用项目唯一登记簿，不给每个空字段预分配编号。

项目领域差异写配置；全局模板集中维护，项目不另建同名复制体系。旧配音史模板仅在[历史归档](../项目/配音史/历史归档/双线研究V1/README.md)保留，不再填写。
